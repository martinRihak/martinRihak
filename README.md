## 🚀 Hlavní projekty

* **[IoT Sensor Dashboard (Bakalářská práce)](https://github.com/martinRihak/Bakalarska_prace)**
  * Full-stack systém pro sběr, ukládání a živou vizualizaci dat ze senzorů (Raspberry Pi) v reálném čase.
  * Přizpůsobitelný drag-and-drop dashboard, JWT autentizace, integrace počasí a kompletní kontejnerizace.
  * **Tech:** `Python (Flask)` `SQLAlchemy` `React` `Docker` `REST API` `JWT`

* **[Zpěvník pro lidové písně](https://lidovyzpevnik.cz/)**
  * Produkční webová aplikace pro vyhledávání, digitalizaci a správu lidových písní i jejich variant.
  * Rychlé filtrování podle regionů a tanců, schvalovací workflow administrátorem a zobrazení textů s akordy.
  * **Tech:** `Python (Django REST Framework)` `PostgreSQL` `React (TypeScript, Vite)` `Cloudflare R2 / S3`

* **[Version Control CLI (Klon Gitu)](https://github.com/martinRihak/versioncontrol)**
  * Příkazový nástroj (CLI) simulující vnitřní architekturu distribuovaného verzovacího systému Git.
  * Vlastní objektová databáze (bloby, stromy, commity) s kryptografickým hashováním (SHA-1), správa staging area.
  * **Tech:** `C++` / `Python` `SHA-1 Hashing` `File System API` `CLI`

* **[WineFactory](https://github.com/martinRihak/WineFactory)**
  * Evidence vín a objednávkový systém pro správu vinařství.
  * **Tech:** `Python (Django)` `SQLite` `HTML5/CSS3`
